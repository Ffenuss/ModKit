# ModKit

Android-приложение для анализа и локальных изменений собственных или разрешённых APK.
Рабочая версия этой ветки: **0.0.30**. Проект не является универсальным автоматическим
моддером: подтверждённые возможности и оставшиеся ограничения перечислены ниже.

## Использование на телефоне

1. Выберите установленную игру, приложение или отдельный APK.
2. Нажмите «Анализ». ModKit определит технологии и проверит доступные рецепты.
3. Отметьте изменения по категориям и нажмите «Создать мод».
4. Дождитесь проверки патчей, подписи и сохранения. Нажмите «Установить».
5. Подтвердите установку в Android и проверьте выбранное действие в приложении.

Основной сценарий не требует root, компьютера, HEX-редактора или облачного сервиса.
В меню «Ещё» находятся экспертный режим и экспорт диагностики с причинами блокировок.

Тестовая сборка называется **ModKit Test** и использует пакет
`io.github.ffenuss.modkit.test`. Она устанавливается рядом с прежним ModKit и
не требует его удаления. История и ключи двух приложений хранятся раздельно.

Один исходный APK даёт один APK. Для установленного приложения со split APK
ModKit сохраняет отдельные APK и передаёт весь набор одной сессией PackageInstaller.
На Android 10+ результат сохраняется в **Загрузки/ModKit**. На Android 8/9
кнопка сохранения предлагает системный выбор папки. Новая попытка не удаляет
предыдущую подписанную сборку.

Если оригинал подписан другим ключом, Android не разрешит обновить его полученным
APK. ModKit не удаляет оригинал. Самостоятельное удаление приложения может стереть
его локальные сохранения — сохраните данные заранее.

## Что поддерживает эта версия

| Область | Поддержка | Граница подтверждения |
|---|---|---|
| DEX | Анализ всех методов поддерживаемых DEX без остановки на 256 кандидатах; константы, чтения полей Z/I/F и вычисления с ветвлениями; переписывание через dexlib2 и повторный разбор | Проверяются все достижимые пути и входные регистры; вызовы, записи, циклы и неизвестные инструкции остаются блокерами |
| Частичная обфускация | Восстановление геттера по фактически читаемому полю; согласованная группа чтений одного поля | Полностью переименованные поля и сложный поток данных пока не восстанавливаются автоматически |
| Unity IL2CPP / ARM64 | Metadata/ELF bindings, файловый индекс адресов, проверка ветвей, выбор конкретного скалярного значения, компактный FMOV, сохранение BTI | Поддерживаемые layouts/инструкции; неизвестные ABI, побочные эффекты и общие тела требуют дополнительного анализа; реальный Unity runtime ещё не испытан |
| Сборка | Одна транзакция для выбранных DEX и native изменений; проверка конфликтов, SHA, diff, выравнивания, подписи и состава APK-set | Успешная сборка не означает работающий игровой эффект |
| Установка | Системное подтверждение, разрешение неизвестного источника, проверка сертификата, один сеанс для split APK, контроль переданных байтов | Поведение OEM и все версии Android требуют отдельной проверки |
| Проверка эффекта | Собственная офлайн-игра и Android UI/функциональные испытания; сценарий ручной проверки и сохранение наблюдения | Наблюдение пользователя не считается автоматическим доказательством |

Список поддерживаемых игровых категорий расширяем. Отсутствие готового рецепта
показывается явно. Серверная авторизация, покупка контента и защищённые серверные
значения не объявляются офлайн-патчами. Root-интерфейс прежних веток в текущем
приложении отсутствует.

## Сборка для разработчиков

Java 17, Gradle 9.5.0, Android SDK 37.0, Build Tools 36.0.0, NDK 28.2.13676358:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

GitHub Actions также запускает `:app:connectedDebugAndroidTest` на Android 10 и 15.
Самостоятельная игра `testgame` содержит механики здоровья и выносливости, связанный
обфусцированный геттер и метод-ловушку с побочным эффектом. Скрипт
`tools/install_device_fixture.sh` устанавливает исключительно эту тестовую игру.
Обычному пользователю эти инструменты не требуются.

CI дополнительно исполняет сформированные Kotlin-кодом ARM64-патчи в Unicorn 2.1.4.
Это независимая проверка машинных инструкций; Unicorn не включён в приложение.

CI debug APK подписывается ключом runner; такой ключ не подходит для постоянных
обновлений. Выдаваемый тестовый APK дополнительно подписывается сохранённым закрытым
тестовым ключом через `tools/SignTestApk.java` (apksig 9.3.0). Ключ не входит в Git.
Установочные сборки из разных каналов могут иметь разные сертификаты.

Действуют [правила разработки](CONTRIBUTING.md) и исходная спецификация проекта.
