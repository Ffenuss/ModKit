# ModKit Test 0.0.32

## Исправление по скриншоту Flick Shot Rogues

Для короткого Float/Double-геттера патч значения 999 может не помещаться до
следующего метода. Раньше после фильтра по размеру выбирался первый вариант,
то есть 0. Теперь положительное значение по умолчанию заменяется ближайшим
положительным доступным значением. Добавлены 16 и 31, которые кодируются
двумя инструкциями FMOV/RET. При достаточном размере остаётся 999.
Значение остаётся доступным для ручного выбора; назначение метода и игровой
эффект не считаются подтверждёнными по имени или успешной сборке.

Регрессии покрывают MaxHealthRaw Float/Double с телом 8 байт, сохранение BTI,
длинное тело, уже существующий множитель и прежние ограничения общих тел.
Реальные байты двух выбранных каталогом патчей отдельно исполняются в Unicorn.

## Восстановление анализа

Журнал хранит последние 128 попыток запуска движков: длительность, последнюю
операцию и файл, счётчики, предупреждения, ошибку, watchdog и получение из кэша.
Контрольные точки сохраняются раз в 2 секунды при фактическом прогрессе;
завершение, отмена и ошибка записываются синхронно. Запись кэша заменяется
атомарно, без предварительного удаления предыдущего файла.

После остановки процесса незавершённая попытка получает INTERRUPTED. Время
простоя не добавляется к длительности. Завершённые стадии остаются доступными
после ошибки/отмены и перезапуска приложения. Отчёт можно открыть прямо после
ошибки, восстановления или срабатывания watchdog, без нового анализа.

ZIP схемы 4 содержит analysis/executions.tsv. Измерения относятся к движкам,
а не ко времени игры. Подготовка входа и быстрый индекс пока не измеряются.
История старых версий отсутствует; её длительности не выдумываются.

## Проверка и ограничения

CI для этого коммита должен пройти JVM/lint/assemble/APK, 5 ARM64-векторов,
Android API29 single APK и API35 split APK. Новая Android-проверка открывает
кэш заново и экспортирует прерванный анализ, не запуская движки.
Результаты проверки и подпись выдаваемого APK будут записаны после завершения CI.

Minecraft: нативные игровые рецепты не добавлены. Aniimo: недостающие валидные
метаданные не восстановлены. Разблокировка Premium сторонних приложений не
реализована. Работа мод-меню на физическом ARM64 и эффект в Flick Shot Rogues
ещё требуют проверки на соответствующем устройстве и APK.
