# ModKit Test 0.0.33 — нативное мод-меню

## Подтверждённые дефекты в коде

Кнопка MK меняла видимость ScrollView, но его дочерняя панель оставалась GONE.
Поэтому внешнее меню не показывало переключатели. Панель теперь видима внутри
раскрываемого контейнера; добавлена Android-проверка её фактической видимости.

Оверлей всегда рисовал выключенные переключатели при создании окна и не
синхронизировался с игрой после перезапуска процесса. Теперь открытая панель
получает согласованный снимок идентификаторов, состояний и PID каждые 1,5 с.
Скрытая панель не опрашивается. До ответа переключатели недоступны. Отсутствие
связи или изменение конфигурации показывается явно; старые ответы от закрытого
окна не меняют новое. После команды отображается состояние, полученное из игры.

Нативная операция, изменение конфигурации и восстановление оригинальных байтов
теперь используют одну блокировку. Старая кнопка из заменённого меню не может
изменить прежний адрес после очистки состояния.

## Проверка

Добавлен собственный `nativefixture`, отдельный от DEX-игры и пользовательских
пакетов. Сборка содержит настоящую восьмибайтовую функцию в ELF, доступную через
JNI. Инструментальный тест читает фактический адрес из ELF, внедряет production
runtime probe, собирает и подписывает APK, устанавливает через PackageInstaller
и нажимает настоящий системный оверлей.

Проверяются исходное значение 7, включение 999, повторное открытие меню,
выключение обратно в 7, отказ для отсутствующего модуля, перезапуск процесса,
замена/очистка конфигурации с восстановлением кода. Исходная нативная библиотека
в APK должна остаться побайтно неизменной до runtime-включения.

CI запускает этот сценарий на Android API29 и API35 x86_64. Fixture также
собирается для ARM64/ARM32/x86; физическое исполнение ARM64 пока не проверено.
Это explicit-рецепт собственной функции, а не проверка автоматического
обнаружения всех функций IL2CPP или игрового эффекта в Flick Shot Rogues.
ARM64-байты каталога дополнительно проверяются существующими пятью векторами
Unicorn.

Первый Android-прогон выявил расхождение UI и accessibility-состояния на API29:
на снимке переключатель уже включён, а проверка узла ждала его подтверждения.
При получении нового состояния панель теперь отправляет событие изменения
поддерева доступности и не переназначает неизменившееся значение переключателя.
Повторный прогон прошёл на обоих API; тест по-прежнему требует одновременно
доступный и правильно отмеченный UI-переключатель, ответ процесса и реальный
результат выполнения функции. При ошибке сохраняются также иерархия окна и
состояние удалённого процесса.

## Использование и границы

Новый протокол снимков находится внутри пересобранного APK игры. После
обновления ModKit нужно заново создать и установить мод. Старую модифицированную
игру нельзя считать обновлённой только после установки самого ModKit.

DEX-патчи остаются статическими; переключаемый DEX-backend ещё не реализован.
Новые нативные рецепты Minecraft, восстановление отсутствующей метадаты Aniimo,
Unreal Blueprint/Dart AOT и Premium сторонних приложений не добавлены.
Серверные значения и недоступный код не становятся изменяемыми от оверлея.
