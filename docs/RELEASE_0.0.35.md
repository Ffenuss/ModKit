# ModKit Test 0.0.35 — одно меню на экране

В Android-проверках 0.0.34 обнаружены две одновременные кнопки MK: внешнее окно
ModKit и встроенное окно в пересобранном приложении. Оба управляли одним набором
модификаций, но занимали экран и затрудняли выбор нужного меню.

Конфигурация теперь явно задаёт режим отображения. Обычный запуск «с мод-меню»
использует только внешнее окно. Экспертный запуск сохраняет встроенное меню по
умолчанию. Режим сохраняется вместе с конфигурацией и восстанавливается после
перезапуска процесса; старые конфигурации без нового поля используют встроенное
меню. Закрытие внешнего окна не включает вторую кнопку: открыть управление снова
можно из ModKit. Состояния модов и прежние правила сброса не изменены.

Для внешнего режима клиент требует явного подтверждения из установленного
приложения. Старый внедрённый код не объявляется поддерживающим новый режим:
нужно заново создать мод из исходного APK и установить его. Встроенный режим
экспертного транспорта остаётся совместимым с прежним протоколом.

Android-проверки считают фактически видимые MK-кнопки при DEX/native запуске,
повторном открытии и перезапуске. Дополнительно проверяются возврат встроенного
меню, сохранение его режима после перезапуска и переход обратно во внешнее меню
с действующим переключателем здоровья. Сохраняются проверки установки одиночного
APK / split APK и все проверки 0.0.34.
